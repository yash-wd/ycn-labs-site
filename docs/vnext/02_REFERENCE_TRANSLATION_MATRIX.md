# YCN Labs vNext — Reference Translation Matrix

**Rule:** References are inspiration. Never copy branding, wording, proprietary media, source code or exact layouts.

---

## 1. Primary references

### Forge Automotive
URL: https://forgeautomotive.co.uk/

**Use**
- One recurring visual protagonist carries the page.
- Large visual-first chapters.
- Camera/detail/return rhythm.
- Short, decisive copy.
- Premium full-screen composition.
- Strong transitions that preserve spatial continuity.
- Each viewport looks intentional when paused.

**Translate to YCN**
- Digital product/device becomes the recurring protagonist.
- Product returns in changed states.
- Close-ups show the customer's action and business-side response.
- Later scenes move to a different visual language rather than repeating the same object forever.

**Do not copy**
- automotive identity;
- red-car treatment;
- assets;
- section order;
- exact easing/timings;
- language.

---

### Celsior
URL: https://celsiortech.com/

**Use**
- Clear enterprise hierarchy.
- Outcome/problem framing before deeper capabilities.
- A stable "How we do it" style section where content changes in one controlled visual frame.
- Platform/data movement as a way to show how work connects.

**Translate to YCN**
- "What needs to improve?" instead of a technology menu.
- Stable pinned method section.

**Do not copy**

- partner logos;
- AI-first claims;
- industry authority claims;
- enterprise scale claims;
- dense technology/platform vocabulary on the homepage.

## 3. Derived YCN design rules

1. A **visual subject carries the argument**.
2. One screen should communicate one main idea.
3. Copy should be short enough to be read while motion is happening.
4. Sections are not stacked cards; they are **chapters**.
5. Movement should create continuity between chapters.
6. Stable pinned frames are valuable when only the state/content needs to change.
7. Device/product visuals are real DOM or carefully authored assets, not fake generated screenshots.
8. Technology is an implementation decision, not first-read content.
9. Proof is separate from promise.
10. Motion should reverse with scroll wherever the experience is scroll-controlled.
